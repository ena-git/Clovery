# Clovery iOS 1.1.0

> 状态：发布候选说明。真机、Sandbox、TestFlight、App Store 审核和分阶段发布完成前不得创建公开 GitHub Release。

## 本次更新

- 新增用户自定义 Clovery ID 与 Clovery 根账户，Apple、Google、华为等身份只作为可替换登录方式。
- 旧版本升级后先显示中文更新说明，再完成登录/注册、原数据迁移、购买权益恢复与 Vault 同步。
- 新增“账户与安全”，可查看 Clovery ID、已绑定登录方式、用户协议与隐私政策，并可在应用内发起账户删除。
- 日记、照片、标签、字体选择和终身权益按 Clovery 账户与 Vault 继承，不再绑定单台设备。
- 继续保留并加强照片保存、分享独立性、购买恢复和跨设备权益校验。

## 数据安全

- 升级、迁移和重试不会主动删除旧版本本地数据。
- 同 ID 冲突内容保留两份，不以“最后写入”静默覆盖。
- Apple 登录身份和 App Store 交易分别验证，不能用邮箱或 Apple ID 猜测合并账户。
- 删除账户先锁定会话与 Vault，再由服务端按隐私政策执行计划删除。

## 兼容与范围

- 支持 iOS 16.0 及以上。
- 本版本仍是原生 Swift/SwiftUI + WKWebView iOS 应用升级，不包含 Flutter、Android 或 HarmonyOS 商店包。
- 保持 `com.clovery.app`、现有 Widget、App Group、iCloud 容器和终身商品标识不变。

## 发布前必须完成

以 `docs/release/ios-1.1.0-acceptance.md` 为唯一验收主表。数据库恢复、完整自动化、两台真机升级、Photos、Sandbox、TestFlight、App Store Connect 商品与审核任一未通过时，不得发布。
